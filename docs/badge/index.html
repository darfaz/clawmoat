Verified Badge Outreach Draft

I’m building ClawMoat, an open-source firewall for AI agents.

Your project touches the exact boundary ClawMoat is built for: agent tools with file, shell, browser, MCP, or network access.

If useful, I can run a free exposure review against the public repo/docs and send a short report. If the findings are clean or fixed, you can add a Secured by ClawMoat badge that links to the report.

No pitch deck. Just the boundary map: what can influence the agent, what it can touch, and what should be blocked or logged.
