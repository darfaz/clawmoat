Run agents on your main computer. Don’t run them naked.

June 6, 2026 · ClawMoat

AI agents are crossing the line from chat toys to real desktop coworkers. That is good. It is also the moment security stops being optional.

The fastest way to make an agent useful is to put it where the work is: your main computer. Your real files. Your browser. Your Gmail. Your Git repos. Your shell. Your calendar. Your Drive. Your background jobs.

That is also the fastest way to give an agent enough access to hurt you.

Prompt injection was cute when agents only chatted. Now they have your laptop.

The old risk was hallucination. The new risk is action.

A chat model can make up a fact. A desktop agent can run a command, read a private file, paste a token into a message, browse a poisoned webpage, install a dependency, push a commit, or keep working after you stop watching.

The answer is not to keep agents trapped on toy machines. That adds friction and kills usefulness. The answer is to run them with a seatbelt.

What the agent seatbelt needs to catch

  • Hidden instructions in webpages, emails, docs, READMEs, support tickets, and MCP tool output.
  • Credential leakage: SSH keys, GitHub tokens, cloud creds, npm tokens, API keys, and secrets in logs.
  • Dangerous tool calls: destructive shell commands, suspicious curl pipes, sensitive file reads, and network exfiltration.
  • Background risk: cron jobs, daemon mode, multiple profiles, local models, and sessions you are not actively supervising.

That is ClawMoat

ClawMoat is runtime security for desktop AI agents. It scans untrusted input before the agent acts, scans tool calls before they execute, scans outbound content before it leaks, and audits sessions so you can see what happened.

In plain English:

Let your agent work. Keep your machine safe.

Before you put an agent on your main laptop

Run a lifecycle audit. Scan the weird docs. Keep credential directories off-limits. Watch background jobs. Require approval for destructive commands and external sends. Keep a trail.

Agents belong on real machines. So does agent security.

npm install -g clawmoat
