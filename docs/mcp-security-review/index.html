Review scope

What we check in an MCP server.

The review focuses on concrete exposure surfaces, not generic model-safety language.

Tool blast radius

  • What each tool can touch
  • Whether permissions match the stated use case
  • Which calls need user approval or policy gates

Untrusted content paths

  • Web pages, files, issues, docs, and tool output
  • Where content enters privileged prompts
  • Poisoning and instruction-smuggling risks

Credential and session exposure

  • Tokens, cookies, local sessions, OAuth flows
  • Logs and persistent memory
  • Outbound paths that can leak sensitive context

Documentation risk

  • Install scripts and setup snippets
  • Permission claims that understate real access
  • Security guidance users can actually follow
