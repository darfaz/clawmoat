What you get

The deliverable is not a generic pitch deck. It is an exposure map: what the agent can touch, what can influence it, what actions need approval, and which ClawMoat-style controls reduce risk.

Where the answer is “ClawMoat is not needed,” the report should say that. The point is trust and clear boundaries, not forcing a tool into every architecture.

What this is not

This is not a full compliance audit, penetration test, legal certification, or claim that a model is safe. It is a practical review of agent tool access and runtime blast radius.

For public open-source projects, we avoid vulnerability-style claims unless there is evidence of a real vulnerability. Most findings are deployment and permission-boundary risks.
