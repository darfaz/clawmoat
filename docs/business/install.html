What It Does

1

Detects Your OS

Identifies Linux, macOS, or WSL and adapts accordingly. No sudo required.

2

Checks Node.js

Verifies Node.js v18+ is installed. Offers to install via nvm if missing — no system packages modified.

3

Installs ClawMoat

npm install -g clawmoat — the open-source AI agent security toolkit.

4

Generates Hardened Config

Creates ~/.clawmoat/config.json with worker-tier permissions, 17+ forbidden credential zones, secret scanning, network logging, and full audit trails.

5

Runs Security Scan

Scans your machine for exposed credentials, insecure permissions, and .env files. Generates a report showing what it found and what's now protected.

6

Prints Next Steps

Configure alert webhooks, run your first scan, connect to your team dashboard.

Frequently Asked Questions

🔒 Is it safe to run?

Yes. The script runs entirely locally — no data is sent anywhere. It installs an npm package, creates a config file in ~/.clawmoat/, and scans for existing credential exposure. No files are modified or deleted. The script is open-source and auditable on GitHub.

📁 What does it change on my system?

It installs the clawmoat npm package globally, creates the ~/.clawmoat/ directory with a config and audit logs, and optionally installs nvm if Node.js is missing. No system files are modified. No sudo required.

🔄 Can I run it multiple times?

Yes, the script is idempotent. Running it again updates ClawMoat and backs up your existing config before generating a new one.

🗑️ Can I uninstall?

Completely. Run npm uninstall -g clawmoat and rm -rf ~/.clawmoat. That's it — nothing else to clean up.

💼 What does --enterprise add?

FinanceGuard for monitoring high-value operations, MCP Firewall in read-only mode for tool-call governance, and SOX compliance audit templates with controls mapping.
