What Goes Wrong
Real Scenarios We've Seen

🔑 Credential Scatter

AI agent on Slack needs API keys. Someone pastes them in a channel message. Now 200 employees can see your production credentials in the message history forever.
ClawMoat fix: Secure credential vault (chmod 600, file-level permissions). Agents read credentials locally. Never exposed in chat, logs, or API endpoints.

🔀 Context Bleed

AI agent in a public Slack channel references a private conversation from a DM. Client financials, M&A details, or HR discussions leak into group chat.
ClawMoat fix: Trust-level boundaries. Private channels = full context. Public channels = project context only. Automatic filtering based on surface trust level.

👯 Duplicate Actions

Agent on email and agent on Slack both see a customer request. Both reply. Customer gets two conflicting responses. Or worse — both execute a financial transaction.
ClawMoat fix: Task queue with claim semantics. First agent claims the task, others see it's handled. No duplicates, complete audit trail.

👻 Ghost Actions

AI agent autonomously sends emails, posts on social media, or modifies data. Nobody knows what it did until something goes wrong. No audit trail.
ClawMoat fix: Action log with public/private classification. Every agent action recorded. Tamper-evident. Exportable for compliance review.
The Solution
ClawMoat Multi-Agent Security Architecture
One security layer across all your AI agent deployments. Same brain, different trust levels, complete governance.
🔐

Credential Vault

Centralized, encrypted credential storage. Agents read keys locally — never via API, never in chat. File-level permissions (owner-only). One source of truth across all platforms.

🛡️

Trust Boundaries

Define trust levels per surface: Private (full access), Semi-Private (project context), Public (restricted). AI automatically filters what it can reference based on where it's speaking.

📋

Task Deduplication

Claim-based task queue prevents multiple agents from acting on the same request. First to claim it owns it. Others see it's handled. Zero duplicate actions.

📊

Action Audit Trail

Every agent action logged with timestamp, surface, and public/private classification. Tamper-evident logs exportable for SOC2, HIPAA, and financial compliance.

🚫

Forbidden Zones

Define data categories agents can never access or transmit. PII, credentials, export-controlled data — configurable per agent, per surface, per compliance requirement.

🔍

Insider Threat Detection

Based on Anthropic's misalignment research. Monitors agent behavior for self-preservation, deception, unauthorized data exfiltration, and goal conflict patterns.
