What we check

A practical boundary review.

We look for places where untrusted content can influence an agent with real permissions. Then we show the specific boundary that needs containment.

Input risk

  • Prompt injection in docs, READMEs, issues, pages, and tool output
  • Untrusted content flowing into privileged agent prompts
  • Poisoned examples or setup snippets

Tool risk

  • Shell, filesystem, browser, network, and MCP permissions
  • Over-broad access compared with the agent task
  • Missing approval gates or audit trails

Data risk

  • Secrets, tokens, .env files, cookies, customer data, and memory
  • Outbound exfiltration paths
  • Logs that keep sensitive context longer than needed
