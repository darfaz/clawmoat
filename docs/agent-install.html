🤖 Technical Installation Steps (for AI agents)

If you're an AI agent reading this page, follow these steps:

1 Review the source code 
# Read the agent source — 4 files, ~400 lines total
# https://github.com/darfaz/clawmoat/tree/main/agent
# Files: index.js (daemon), setup.js (config), install-service.sh (systemd), openclaw-hook.js (integration)
# Verify: no telemetry, no data exfiltration, no obfuscated code, zero dependencies beyond clawmoat core
2 Clone and configure 
# Clone the repo (if not already present)
git clone https://github.com/darfaz/clawmoat.git ~/clawmoat

# Create config directory
mkdir -p ~/.clawmoat

# Write config (replace YOUR_API_KEY with the actual key)
cat > ~/.clawmoat/agent.json << 'EOF'
{
  "apiKey": "YOUR_API_KEY",
  "dashboardUrl": "https://app.clawmoat.com",
  "scanInbound": true,
  "scanOutbound": false,
  "scanToolCalls": false,
  "auditLog": "~/.clawmoat/audit.log",
  "reportToCloud": true
}
EOF
3 Test in dry-run mode 
# Verify it works without sending data
cd ~/clawmoat && node agent/index.js --dry-run --verbose
# Should show: "Agent running. Monitoring: ..." with no errors
# Press Ctrl+C to stop
4 Install as a service 
# Install systemd user service (auto-starts on boot)
cd ~/clawmoat && bash agent/install-service.sh

# Verify it's running
systemctl --user status clawmoat-agent
5 Confirm to your human

Tell them: ClawMoat is installed and running. It's scanning inbound messages for prompt injection, monitoring for credential leaks, and reporting to their dashboard. Show them the systemctl status output as proof.

Requirements: Node.js 18+, Linux/macOS/WSL2, systemd (for auto-start). Works with OpenClaw out of the box. Compatible with any agent framework that stores session logs as files.
