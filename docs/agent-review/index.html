Agent-reviewed trust workflow

Let your agent review ClawMoat before you trust ClawMoat.

Security software has a trust problem. The honest answer is not louder claims. The honest answer is inspection. Use your own coding agent to review ClawMoat's repo, package, install path, network behavior, and business model before you install or buy.

The workflow

1. Point your agent at ClawMoat

Use Claude Code, Cursor, Codex, Windsurf, or another coding agent. Give it the repo and this page.

2. Make it skeptical

Ask it to inspect package scripts, dependencies, network calls, filesystem access, secrets handling, and checkout behavior.

3. Decide from its report

If your agent says the tool is sketchy, do not install it. If it says the tradeoff is sane, install the free scanner or buy the seatbelt.

This is not a gimmick. It matches the buyer psychology: people distrust security products because the product itself could be malware. So the first product experience should be independent review, not blind installation.

Prompt to give your agent

You are my skeptical security reviewer. Review ClawMoat before I install or buy it.

Repository: https://github.com/darfaz/clawmoat
Website: https://clawmoat.com

I want a blunt report answering:
1. What does ClawMoat claim to do?
2. What files, commands, environment variables, network calls, and package scripts does it use?
3. Does the install path look safe for a developer workstation?
4. Does it upload code, secrets, scan results, or local data by default?
5. Are there suspicious dependencies, postinstall scripts, obfuscated code, telemetry, or payment-flow issues?
6. What risks remain even if the code looks clean?
7. Is it worth using as a seatbelt for Claude Code, Cursor, Codex, Windsurf, MCP servers, and local coding agents?

Do not trust the marketing copy. Inspect the actual files and commands. Give me:
- Safe findings
- Risky findings
- Unknowns
- Final recommendation: install, wait, or avoid

What ClawMoat should pass

No blind trust

The review should be runnable before install, from public files and explicit commands.

No surprise uploads

Local scans should stay local unless the user deliberately enables a hosted or checkout workflow.

No magic claims

ClawMoat is a seatbelt and scanner. It is not a guarantee that agents can never be exploited.
