Team rollout

Put the same coding-agent seatbelt on every developer.

Team is deliberately small-scope: shared policy, CI checks, reports, and support. No custom implementation. No enterprise dashboard promise. This keeps the product self-serve and supportable.

Start Team trial

Who Team is for

  • 2 to 10 developers using Claude Code, Cursor, Codex, Copilot, Windsurf, or MCP tools.
  • Teams that want a standard policy before people click “always allow.”
  • Founders and platform leads who need quick evidence without buying an enterprise AI firewall.

What Team includes

  • Shared clawmoat.yml policy examples.
  • Repo and MCP scan workflows.
  • Markdown/JSON report output for review.
  • CI-friendly commands and support docs.
  • Email support with a 48-hour target.

10-minute rollout

  1. Install the CLI.
  2. Activate the Team license from the checkout email.
  3. Run an MCP and repo scan locally.
  4. Commit a shared policy file.
  5. Add the CI command to fail on critical findings.
npm install -g clawmoat
clawmoat activate CM-XXXXX-XXXXX-XXXXX-XXXXX
clawmoat scan-mcp --json
clawmoat lifecycle audit --path . --format markdown --output clawmoat-report.md
clawmoat ci .

Starter policy

version: 1
agent:
  mode: team
policies:
  block_secret_reads: true
  block_suspicious_egress: true
  require_approval_for_shell: true
  require_approval_for_mcp_servers: true
reporting:
  formats: [json, markdown]

Support boundary

Team support covers activation, docs, policy examples, and product bugs. It does not include custom remediation, client-specific reports, compliance certification, or managed security operations.

Agency is not the main funnel yet. If you need white-label multi-client reports, email us, but we are not driving paid traffic there until the workflow is productized.
